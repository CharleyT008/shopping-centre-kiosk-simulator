🏬 Shopping Centre Kiosk Simulator
A Python-based shopping centre kiosk simulator developed as a software development challenge project. The application provides an interactive information point similar to those found in modern shopping centres, allowing visitors to access navigation, store information, parking services, accessibility options, and more.

✨ Features
🗺️ Interactive shopping centre map
🔍 Store and facility search
🚗 Parking reservation system
♿ Accessibility options
🌍 Multiple language support
🎉 Event and promotion information
📍 Visitor wayfinding and guidance
🚨 Emergency information screen
🖥️ User-friendly kiosk-style interface
🛠 Technologies Used
Python
Tkinter
Object-Oriented Programming (OOP)
GUI Development
📖 Project Overview
This project was created as a personal programming challenge to explore GUI development, user interface design, accessibility considerations, and software architecture using Python.

The aim was to replicate the functionality of a real-world shopping centre information kiosk while developing practical software engineering skills.

⚠️ Disclaimer
This project is an independent educational project created for learning and portfolio purposes. It is not affiliated with, endorsed by, or connected to any shopping centre, retail organisation, or commercial entity.
